Not set yet. This file has no rules and no Scoring section, so the agent won't score any article until an admin replaces it with the org's guideline (see `AGENTS.md` → Guideline and scoring).

The guideline needs:

- A Rules section: one line per rule, each with an ID (G1, G2, ...), whether it is a "must" or a "should", and what the article has to do. For example: "**G1** (must) The title names the question or task in the customer's words."
- A Scoring section: the points per rule, the total, and what it takes to pass. For example: one point per rule met; an article passes only if it meets every "must" rule and scores at least 7 out of 9.
